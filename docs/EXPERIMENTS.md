# Gens — Experiment Log

Policy (Phase 0 §0.5): risky or exploratory work happens on `experiment/<topic>` branches, never on phase branches or `main`. Every experiment gets an entry here **regardless of outcome** — failed experiments are as valuable as successful ones, provided they are documented. An experiment may only be merged into a phase branch together with a decision record in `docs/DECISIONS.md`.

Experiment naming: `experiment/<phase>-<topic>` (e.g. `experiment/2-gpu-driven-culling`).

Entry format:

```
### E-### — <title>
- BRANCH: experiment/...
- QUESTION: what exactly are we testing?
- METHOD: how?
- RESULT: what happened (with metrics/evidence paths)?
- DECISION: adopt / reject / iterate — and the ADR that records it.
```
